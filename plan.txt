Rol y Objetivo:
Actúa como un Arquitecto de Software Senior y experto en desarrollo web. Quiero construir un SaaS B2B (Software as a Service) integral para establecimientos de comida (restaurantes, cafeterías, heladerías). El sistema debe ser multi-tenant, escalable y muy fácil de usar para transformar digitalmente a mis clientes.

Características Principales del Sistema:

Suscripción y Multi-tenant: Los clientes acceden pagando una suscripción. Los datos de cada restaurante deben estar completamente aislados.

Gestión de Inventario Automatizada: El cliente añade productos, categorías y detalles, y estos se reflejan automáticamente en el catálogo público y en el Punto de Venta (POS).

Gestión de Personal (RRHH): Control de turnos, horarios y salarios.

Sistema de Punto de Venta (POS): Interfaz rápida para cajeros.

Presencia en Línea: Generación automática de un catálogo, pedidos en línea y landing page personalizable por el dueño del restaurante.

Pantalla de Cocina (KDS): Despliegue de pedidos en tiempo real para los cocineros.

Gestión de Mesas: Módulo para que los meseros tomen pedidos y asignen mesas.

Roles y Permisos (RBAC): Admin (Dueño), Operador/Cajero (POS), Cocinero (KDS), Mesero (Mesas/Pedidos). Todo altamente personalizable por el Admin.
